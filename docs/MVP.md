# Chi Toolbox MVP 범위

개인 대시보드에서 읽지 않은 학교 소식과 남은 과제를 확인한다. 첫 버전의 LMS 이용 대상은 본인 계정이다.

| 화면 | 제공할 경험 |
| --- | --- |
| 대시보드 | 새 소식과 남은 과제를 숫자로 요약한다. 카드는 화면 크기에 따라 자동 배치하고, 누르면 해당 LMS 탭을 연다. |
| 탐색 | PC에서는 왼쪽 메뉴, 모바일에서는 하단 메뉴를 사용한다. LMS 안에서는 새 소식과 남은 과제를 탭으로 전환한다. |
| 새 소식 | 첫 수집은 기준선으로 저장한다. 이후 신규·변경 소식을 아래로 쌓고, 다시 방문하면 첫 미확인 소식부터 읽는다. |
| 남은 과제 | 최초 수집부터 기존 과제를 포함한다. 미제출·기한 전 과제를 기한순으로 보여주고 기한 경과·확인 필요 항목은 구분한다. |
| 접근·연결 상태 | 소유자만 LMS 자료를 열람한다. 마지막 동기화 시각을 제공하고, 수집 전·수집 실패·세션 만료를 실제 0건과 구분한다. |

**진입점 결정(2026-11-03)** 새 대시보드는 `/toolbox`에서 사용한다. 기본 주소 `/` 전환은 기능을 더 개발한 뒤 진행한다.

## 화면 작업 순서와 상태

| 순서 | 작업 | 시작점과 완료 기준 |
| --- | --- | --- |
| 1 | 로그인 화면 · 검증 완료 | `/dev/login`은 PC에서 Google·이메일을 좌우로, 모바일에서 이메일을 먼저 표시한다. 11월 3일 배포 후 사용자가 실계정 로그인과 `/dev/dashboard` 복귀를 확인했다. |
| 2 | 회원가입 화면 | 같은 폼의 기존 가입 모드를 활용한다. 로그인 화면에서 가입으로 이동하고, 입력 오류를 수정하거나 가입 응답에 따른 다음 행동을 확인한 뒤 로그인으로 돌아갈 수 있어야 한다. |
| 3 | 설정 화면 | 현재 `/toolbox/settings`는 빈 화면이다. 먼저 사용자가 여기서 확인하거나 바꿀 항목과 저장 범위를 정한다. 합의한 항목을 구현하고 PC·모바일 메뉴에서 진입해 결과를 확인한다. |

세 화면을 마친 뒤 삼성 헬스 연동과 가계부의 착수 순서를 다시 논의한다.

## 이후 기능 후보

- 직접 작성하는 할 일과 반복 루틴
- 주간 일정과 캘린더
- 개인 노트
- 가계부와 이번 달 지출
- 삼성 헬스·워치 건강 지표, 구글 드라이브 접근
- 다른 사용자의 개별 LMS 연결

후속 기능을 선택하면 대시보드에 보여줄 값과 상세 화면에서 완료할 행동을 정한다. 구현·운영 상태는 [작업 컨텍스트](../CODEX_CONTEXT.md)에서 확인한다.
