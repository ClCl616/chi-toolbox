# LMS 피드 화면 개선 · 최종 상태

## 화면 동작

- /v2/lms와 과제 화면의 새 소식·남은 과제 탭은 스크롤 시 상단에 고정된다. 불투명 배경으로 뒤 메시지와 겹치지 않는다.
- 소식은 왼쪽, 상태 알림은 오른쪽 말풍선·아이콘으로 표시한다. 경고/복구 색상과 내용 펼침·접힘, 읽음 표시를 유지한다.
- 메시지 영역은 내용에 맞추되 기본 최소240px, 최대800px로 제한한다. 좁은 화면에서는 아이콘·간격을 제외한 가용 너비가 우선이다. 과목명·말풍선·시간을 같은 너비 안에 배치한다. 긴 제목이나 공백 없는 본문은 줄바꿈한다.
- 고정 탭 높이를 읽음 판정 영역에서 제외한다.
- 변경: features/lms/components/lms-workspace.module.css, lms-feed.tsx. 수집·API·DB·인증 계약은 바꾸지 않았다.

## 검증

기본 검사(구조·타입·린트·단위19개), dummy production 빌드, Edge LMS 회귀, HTTP smoke, git diff --check 통과. 브라우저 검사는 격리된 임시 snapshot/read 파일과 합성 데이터만 사용한다.

1440/390/320px에서 sticky 위치, 소식 왼쪽/상태 오른쪽 배치, 최소 너비, 긴 과목명+한 글자 제목의 과목명/시간 경계, 긴 본문 펼침/접힘, 가로 넘침 없음, 탭 전환을 검사했다. 기존 읽음 저장·복귀·실패 처리도 통과했다. PC·모바일 스크린샷을 확인했다.

운영 주소에서도 합성 API 응답으로 최종 정렬을 확인했다. 실제 개인정보·읽음 상태는 변경하지 않았다. health200과 미로그인 LMS API401을 확인했다.

## 배포와 복구

최종 구현 커밋은 2f1da1c, 웹 릴리스는 20261112-134237-450-2f1da1c41902다. 기존 deploy/windows/deploy.ps1로 production 후보 빌드·health 검사 후 전환했다. LMS 수집기는 이번 화면 배포에서 재시작하지 않았다. 복구는 rollback.ps1로 이전 웹 릴리스를 선택한다.

중간 이력은 a41e031(탭/좌우 정렬), 9944433(내용 너비), 2f1da1c(최소 너비·공통 정렬)다. 9944433의 과목명/말풍선 너비 분리는 최종 정책에서 대체됐다.

첫 배포 실행에서는 PowerShell의 native stderr 처리가 빌드 안내 문구를 오류로 처리했다. 기존 릴리스가 유지됨을 확인하고 hidden Start-Process로 stdout/stderr를 분리해 완료했다.
