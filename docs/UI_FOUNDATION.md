# 공통 UI와 빈 화면

## 범위와 확인 경로

새 MVP의 공통 UI는 `/toolbox`에서 확인한다. 기존 `/`, `?view=...`, 로그인·API·운영 데이터는 유지한다. 미완성 MVP로 기존 서비스를 교체하지 않기 위한 단계적 진입점이며, 별도 앱이나 복제 저장소가 아니다.

| 경로 | 화면 |
| --- | --- |
| `/toolbox` | 자동 배치 수치 카드 캔버스 |
| `/toolbox/lms` | 새 소식·장애/복구 피드, 미연결/빈 상태 |
| `/toolbox/lms/assignments` | 남은·기한 경과·확인 필요 과제 |
| `/toolbox/settings` | 현재 설정 범위 안내 |

PC는 왼쪽 내비게이션, 820px 이하는 하단 내비게이션이다. LMS는 새 소식 / 남은 과제 탭 경로로 나뉘며 직접 URL 접근·새로고침·뒤로 가기를 지원한다. 데이터가 없으므로 집계값 `0`이나 가짜 메시지를 표시하지 않고 `—`와 연결 필요 안내를 표시한다.

공개 환경에서는 LMS 데이터 API가 비활성이다. 로컬 preview에서만 별도 수집기의 개인 자료를 읽는다. 기존 로그인 화면과 인증 서버는 변경하지 않는다. 공개 연결 전에는 사용자 인증·소유권 경계를 적용해야 한다. [로컬 LMS 동작·제약](LMS_LOCAL.md)을 따른다.

## 파일 소유권

- `app/toolbox/`: 얇은 URL 진입점, 레이아웃, 로딩·오류 경계.
- `shell/toolbox/`: 공통 내비게이션·반응형·색상 토큰.
- `features/dashboard/`: 수치 카드와 자동 배치·가로 스크롤 캔버스.
- `features/lms/`: LMS 모델·조회/읽음 훅·로컬 전용 API·피드/과제 화면. Python 수집 어댑터는 `workers/lms/`.
- `features/settings/components/toolbox-settings.tsx`: 현재 설정 범위 안내.
- `shared/components/toolbox-ui.*`: 공통 페이지 헤더, 버튼 스타일, 로딩·미연결·빈 상태·오류 표시.

CSS Module을 각 소유 파일 옆에 두고 새 전역 CSS나 기존 스타일 override를 추가하지 않는다. 기존 workspaces registry는 운영 화면용이며, 신규 `/toolbox` 화면을 그 registry에 중복 등록하지 않는다. 공통 요소는 두 기능에서 실제로 재사용할 때 추출한다.

## 카드 캔버스 계약

- 카드 제목·수치·필요한 상태만 표시한다. 소개 문구·슬로건·중복 이동 안내는 제외한다.
- 카드 전체가 해당 LMS 탭으로 연결된다. 미연결 값은 `—`로 표시하고 가짜 그래프나 수치를 추가하지 않는다.
- 카드 편집·표시 설정·사용자 순서 변경·localStorage 저장 로직은 제거했다. 이전 저장 키는 읽거나 삭제하지 않는다.
- 대시보드는 메뉴를 제외한 높이를 채운다. 소수 카드는 가용 영역을 나누고, 개수가 늘면 2행으로 자동 배치한다.
- 최소 카드 너비를 넘으면 캔버스가 가로로 확장된다. 페이지 구분·스크롤 스냅 없이 휠·트랙패드·터치와 키보드 링크 포커스로 이동한다.
- 모바일도 캔버스만 가로 이동하며 하단 메뉴는 고정한다. 높이가 600px 이하이면 1행으로 전환한다.
- 실제 카드 증가는 기능 추가 시 이루어진다. 다수 카드 검증은 브라우저 테스트의 DOM 배치 fixture에서만 수행한다.

## 검증

로컬 화면 확인: `npm.cmd run build:test` 후 `npm.cmd run preview:toolbox`를 실행하고 `http://127.0.0.1:13003/toolbox`를 연다. dummy 환경을 사용하며 운영 환경 파일을 읽지 않는다. 개발 포트는 외부에 공개하지 않는다. 2026-11-01 캔버스 변경은 사용자 요청에 따라 로컬 검증만 하며 배포하지 않는다.

```powershell
npm.cmd run check
npm.cmd run build:test
npm.cmd run test:smoke
$env:TEST_BROWSER='msedge'
npm.cmd run test:toolbox
npm.cmd run test:browser
```

`test:toolbox`는 dummy production 서버를 자동 시작·종료한다. 비활성 LMS 조회 API만 허용하고 다른 API 요청이 없는지 확인한다. 화면 이동·히스토리·4개 경로·8개 화면 크기·1~16개 카드의 수평 확장, 세로 스크롤 방지, 휠·키보드 포커스 이동을 검사한다. 캡처는 Git 제외 `work/qa/toolbox-*.png`에 저장한다. 기존 `test:browser`는 기존 서비스 회귀 검사다. `test:lms`는 임시 자료로 실제 로컬 API와 LMS 화면을 검사한다. 실제 DB 쓰기나 LMS 수집을 실행하지 않는다.
